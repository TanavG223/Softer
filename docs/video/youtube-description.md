# Softer — private mental wellbeing support for macOS

Softer is a private native Mac app designed to make the next stressful minute
smaller. It offers one clear activity at a time, an adjustable breathing pacer,
finite scoreless focus games, explicit local-only adaptation, and visible human
support routes.

Softer is a non-clinical wellbeing tool. It does not diagnose, treat, detect a
crisis, or replace professional or emergency care. The software checks described
in this video verify product behavior; they are not evidence of a mental-health
outcome.
