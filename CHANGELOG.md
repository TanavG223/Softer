# Changelog

## 0.4.0 — 2026-09-04

- Rename the product to Softer: a short, modern identity for the app's
  low-pressure, reversible interaction standard.
- Preserve the legacy bundle identifier, Keychain service, preferences, and
  encrypted profile directory so the brand change does not strand saved data.
- Refresh the app, website, documentation, release package, and two-person demo
  script with the new name.

## 0.3.1 — 2026-09-03

- Correct the version displayed in the native About screen.
- Preserve native link semantics for support actions on the public project page.
- Correct the game-card, support-section, and research-label contrast in both
  light and dark themes.
- Produce a versioned universal ZIP and SHA-256 during macOS packaging.
- Add repository contribution and security guidance.

## 0.3.0 — 2026-09-03

- Lower the minimum deployment target to macOS 14 and publish a universal app.
- Add an adjustable, pausable breathing pacer with shape-only and reduced-motion modes.
- Rework Harbor Tiles into branching, hidden-answer puzzles with Hint and Undo.
- Make trusted-person and professional-care support routes actionable with confirmation.
- Add a memory-only guest path and preserve fail-closed encrypted-workspace behavior.
- Improve contrast, scaling, accessibility labels, safety copy, documentation, and public release evidence.
