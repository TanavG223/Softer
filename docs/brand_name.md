# Softer name and compatibility boundary

**Softer** names the interaction standard rather than promising a health
outcome: fewer decisions, lower pressure, reversible actions, and a clear way
out. It is short, conversational, easy to say on video, and flexible enough to
cover breathing, movement, connection, planning, and finite play. The tagline
remains: **make the next minute smaller**.

On September 4, 2026, focused exact-name searches found no matching consumer
mental-wellbeing app or Devpost project. The target repository path
`TanavG223/Softer` also returned GitHub's not-found page before the rename. An
unrelated GitHub organization uses the common word `softer`, so this is only a
practical collision check—not trademark clearance or legal advice.

The user-facing app, package, site, documentation, and submission materials use
Softer beginning with version 0.4.0. The bundle identifier, Keychain service,
preference keys, Swift module names, and encrypted profile directory retain the
legacy internal `paceback` or `PaceBack` identifiers. Keeping those identifiers
stable allows the renamed app to open existing encrypted profiles instead of
silently creating an empty workspace.
